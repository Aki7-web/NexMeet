
# NexMeet 🎥

**A web-based video conferencing application for online communication and collaboration.**

NexMeet is a full-stack project built to make online meetings accessible through a web application. The project separates the frontend and backend into dedicated directories and is deployed online.

🔗 **[Live Demo](https://nexmeetfrontend-updg.onrender.com/)**

📦 **[GitHub Repository](https://github.com/Aki7-web/NexMeet)**



## ✨ Overview

NexMeet explores the development of a real-time communication application, bringing together a web interface and backend services to support video conferencing.

The project demonstrates practical software development, frontend-backend integration, and deploying a web application for public access.

## 🚀 Features

- **Video Conferencing:** A web-based interface for video meetings.
- **Full-Stack Architecture:** Separate frontend and backend codebases.
- **Live Deployment:** An online version available to try through the live demo.
- **Modular Structure:** Frontend and backend components organized separately.


## 🛠️ Tech Stack

- **Frontend:** React.js
- **Backend:** Node.js
- **Database:** MongoDB
- **Real-Time Video & Audio:** WebRTC
- **Real-Time Communication & Signaling:** Socket.IO / WebSockets
- **Deployment:** Render

## 🏗️ Architecture

NexMeet uses a full-stack architecture with React powering the frontend and Node.js handling backend operations. WebRTC enables real-time audio and video communication, while sockets support real-time signaling and coordination between connected clients. MongoDB provides database storage.

## ⚙️ Getting Started

### Prerequisites

Install the tools required by the frontend and backend projects.

### 1. Clone the repository

```bash
git clone https://github.com/Aki7-web/NexMeet.git
cd NexMeet
```

### 2. Set up the backend

```bash
cd backend
```

Install dependencies and configure environment variables according to the backend's setup instructions.

### 3. Set up the frontend

Open a separate terminal:

```bash
cd NexMeet/frontend
```

Install dependencies and configure the backend URL as required by the frontend.

### 4. Run the application

Start the backend and frontend using the development commands defined in their respective project configuration files.

**Note:** Refer to the scripts and configuration files in each directory for the exact commands and required environment variables.
